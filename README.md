Boolean admissibility and the q/s ceiling for graph positive inertia: exact linearisation, the s=1 case, certified data, and a conjectured barrier at 3

## Overview

`inertia-admissible-polynomials` provides algorithmic implementations and mathematical models for scientific and cryptographic applications, focusing on numerical stability, invariant verification, and performance.

## Getting Started

```bash
git clone https://github.com/rajveersinh-is-dev/inertia-admissible-polynomials.git
cd inertia-admissible-polynomials
pip install -r requirements.txt
```

Run the automated verification suite:

```bash
pytest tests/
```
